# 水下视觉数据集汇总 (Underwater Vision Datasets)
---

For the English version of the README, please visit [ ](./README-EN.md).

---
> 本仓库整理了水下视觉相关的公开数据集，包括图像增强、图像分类、目标检测、语义分割、实例分割、显著伪装目标检测、目标跟踪以及水下三维重建等任务。
> 
> 🌟 如果对您的研究有帮助，欢迎 Star！
> 
> 📝 对应论文：[面向海洋智能的水下视觉数据集综述]/[A survey of underwater visual datasets for ocean intelligence]

## 🔍 如何使用本仓库

1. 根据您的研究任务选择合适的数据集类别
2. 查看表格中的详细信息（数量、类型、特点等）
3. 先查看备注看链接是否有效
4. 点击"Download"链接获取数据集
